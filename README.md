# ForeverLove - Anniversary Gifts Store 💖

An attractive, romantic, and interactive **Anniversary Gift Webpage** built exclusively using **pure HTML5, CSS3, and Vanilla JavaScript**.

This project was built for the **Full Stack Development Tools - Team Challenge** focused on the **Anniversary Gifts** module.

---

## ✨ Key Features

1. **Floating Flying Hearts Engine (💖)**
   - Continuous romantic background floating hearts rising dynamically across the screen.
   - Click-to-burst particle heart effect on cursor click.

2. **Anniversary Milestone Collections**
   - 1st Year (Paper & Cotton Tradition)
   - 5th Year (Wooden Keepsakes & Plaques)
   - 10th Year (Tin & Diamond Accents)
   - 25th Year (Silver Jubilee Specials 🥈)
   - 50th Year (Golden Jubilee Specials 🥇)

3. **Product Catalogue & Interactive Filtering**
   - Filter by categories (*Personalized*, *Jewelry & Accessories*, *Romantic Keepsakes*, *Light & Decor*).
   - Real-time instant search bar.
   - Price & Rating Sorting.
   - Heart Wishlist toggle with interactive count badge.

4. **Interactive Customization & Shopping Cart**
   - **Quick View Modal**: Inspect gift details and enter custom engraving / couple names.
   - **Slide-over Cart Drawer**: Manage item quantities, subtotal calculation, and promo code support (`LOVE2026` for 15% discount).

5. **Personalized Love Note Generator 💌**
   - Interactive form to type Partner Name, Sender Name, Milestone Years, and custom romantic messages.
   - Live visual card preview with theme selector (Romantic Rose, Midnight Starry, Golden Elegant).
   - Copy Card text to clipboard or trigger print/save.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic tags, accessible structure.
- **CSS3**: CSS Grid, Flexbox, Custom Properties (variables), Glassmorphism, Responsive Breakpoints (`@media`), Keyframe Animations (`@keyframes floatUp`).
- **JavaScript (ES6+)**: DOM manipulation, array filtering & sorting, event listeners, dynamic cart calculation, particle effects.
- **Iconography & Fonts**: Font Awesome 6.4, Google Fonts (*Playfair Display*, *Poppins*, *Great Vibes*).

---

## 🚀 How to Run

1. Clone or download the repository into your local directory.
2. Open `index.html` directly in any web browser (Chrome, Edge, Firefox, Safari).
3. No server or build setup required!
